# Customer Shopping Behavior Analysis

## 📌 Project Overview
This project analyzes customer shopping behavior using Python, SQL, and Power BI to uncover valuable business insights related to customer spending patterns, subscriptions, discounts, and purchasing trends.

---

## 🎯 Objectives
- Analyze customer purchasing behavior
- Identify revenue-driving customer segments
- Study discount impact on sales
- Build an interactive Power BI dashboard
- Generate business insights for decision-making

---

## 🛠️ Tools & Technologies

- Power BI
